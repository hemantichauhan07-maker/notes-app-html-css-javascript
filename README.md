# 📝 Notes App

A modern and responsive **Notes Management Application** developed using **HTML5, CSS3, and JavaScript**.

The application provides a clean and organized interface for users to create, manage, search, edit, archive, and delete their notes. It also includes folder management, calendar navigation, and a trash section to provide a complete note-management experience.

---

## 📌 Project Overview

The Notes App is designed as a simple productivity application where users can manage their personal notes in an organized way.

The interface is divided into different sections such as:

- My Notes
- Recent Folders
- Add New Note
- Search
- Calendar
- Archive
- Trash
- New Folder

The project focuses on creating a clean user interface and implementing interactive functionality using JavaScript.

---

## 🛠️ Technologies Used

### HTML5

HTML5 is used to create the complete structure and layout of the application.

It is used for:

- Creating the sidebar navigation
- Creating the main Notes section
- Creating the Recent Folders section
- Creating note cards
- Creating buttons and action controls
- Creating the search input
- Creating the New Folder section
- Structuring the Calendar, Archive, and Trash navigation
- Organizing the overall page content using semantic HTML elements

---

### CSS3

CSS3 is used to design and style the Notes App and make the interface clean and user-friendly.

It is used for:

- Creating the overall page layout
- Designing the sidebar and navigation menu
- Styling the note cards
- Applying different background colors to notes and folders
- Managing spacing, padding, and margins
- Creating rounded corners and shadows
- Styling buttons and icons
- Designing the search box
- Creating responsive layouts
- Improving typography, alignment, and visual appearance

The CSS also helps maintain a consistent and modern design throughout the application.

---

### JavaScript

JavaScript is used to add interactivity and functionality to the Notes App.

It is used for:

- Creating new notes
- Editing existing notes
- Deleting notes
- Searching notes
- Creating and managing folders
- Handling user interactions
- Updating note content dynamically
- Managing Archive and Trash functionality
- Adding and removing elements dynamically
- Handling button and click events
- Updating the application interface based on user actions

JavaScript makes the application interactive instead of being a static HTML/CSS website.

## 🎨 UI Design

The application uses a clean dashboard-style layout with:

- Left-side navigation panel
- Main content area
- Recent folder cards
- Color-coded note cards
- Search functionality
- Action icons for editing and deleting notes
- Simple and minimal visual design

The design focuses on **simplicity, readability, spacing, alignment, and user-friendly navigation**.
